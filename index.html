Q

Query

What am I looking for?

K

Key

What do I have? Compatibility measure with other tokens.

V

Value

The actual content to be retrieved.

Position

Positional Encoding

Tokens are processed in parallel, so sine/cosine or learned embeddings inject order.

Stability

Residual + LayerNorm

Skip connections help gradient flow; LayerNorm stabilizes training.

Scale

Scaled Dot-Product

Dividing by √dₖ prevents huge values in softmax.

Key idea

Beats RNNs

Parallel processing of all tokens at once.

Evaluation Metrics

0–1

BLEU

Machine translation. N-gram precision vs reference.

0–1

ROUGE

Summarization. N-gram recall vs reference.

0–1

F1-Score

Classification. Harmonic mean of precision and recall.

lower = better

Perplexity

How well a language model predicts text.

−1 to 1

Cosine Similarity

Angle between embedding vectors.

Exam trap: higher BLEU = more similar to the reference text. Not broader vocabulary, not better understanding.

Training & Optimization

PEFT

LoRA / Adapters / Prompt tuning

Low-rank matrices, small inserted modules, or optimized prompts instead of full fine-tuning.

Risk

Catastrophic Forgetting

Model loses pre-trained knowledge while fine-tuning.

Technique

Gradient Accumulation

Simulates larger batches with limited memory.

Technique

LR Warm-up, Dropout

Stabilize early training; prevent overfitting.

Optimization

Quantization

FP32 → INT8: smaller, faster, less power, small accuracy cost.

Optimization

Distillation

Student learns the teacher’s soft probabilities.

Tokens

Subword (BPE, WordPiece)

Handles out-of-vocabulary words, smaller vocabulary.

Generation

Beam, top-p, Temperature

Beam explores candidates; top-p samples a probability mass; higher temperature = more diverse.

Prompting & RAG

Prompt

Zero-shot / Few-shot

Task only, or a few examples. No fine-tuning needed.

Prompt

Chain-of-Thought

Best technique for multi-step reasoning.

RAG

Retrieve, then generate

Reduces hallucination, gives up-to-date knowledge. Chunking splits text for retrieval.

Deploy

A/B testing

Serve both models 50/50 for a fair comparison.

Ethics & Alignment

Red-teaming

Hallucination
